# Man Matters Routine & Wellness Tracker

A daily wellness habit and routine tracker web application for Man Matters products with progress checkups, low-stock reminders, and the Sahil AI assistant.

## Features
- **Daily Routine Tracker:** Log daily gummy doses with meal timing (before/after meals).
- **Streak & Adherence:** Visual streak counter and progress statistics.
- **Stock Alert & Reorder:** Tracks remaining doses and triggers reorder links when stock runs low.
- **Progress Checkup:** Track strand counts and hairline checkup photos over time.
- **Sahil AI Assistant:** Offline product specialist chatbot for Man Matters hair, sleep, and performance products.

## Tech Stack
- React 18
- TypeScript
- Vite
- Tailwind CSS
- Lucide React

## Getting Started

1. **Install dependencies:**
   ```bash
   npm install
   ```

2. **Start the local development server:**
   ```bash
   npm run dev
   ```

3. **Build for production:**
   ```bash
   npm run build
   ```
